<h2>Funcionalidades:</h2>

* Buscar libro en la API [Gutendex](https://gutendex.com/)
* Desplegar un menu con diferentes opciones
* Guardar libro en base de datos postgreSQL
* Mostrar libros agregados a la bd
* Mostrar los 5 libros mas descargados
* Mostrar libros por lenguaje y cantidad en ese lenguaje
* Mostrar libros por cantidad de descargas minima
* Mostrar todos los autores de los libros en la base de datos
* Mostrar autores que estaban/estan vivos en determinado año

## Uso:
Deben crear una base de datos "literalura" o el nombre que prefiera siempre que lo cambie en el archivo "application.properties" en PgAdmin4

## API:
[Gutendex](https://gutendex.com/)
